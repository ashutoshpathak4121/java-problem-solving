## 🧩 Problem-Solving Approach

For each problem, I try to follow this process:

```text
1. Understand the Problem
        ↓
2. Identify the Pattern
        ↓
3. Develop the Logic
        ↓
4. Write the Algorithm
        ↓
5. Implement in Java
        ↓
6. Test with Examples
        ↓
7. Analyze Time & Space Complexity
```
